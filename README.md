# Project Overview

This repository contains code and notebooks for experiments with robot policies and learned world models.

- [`gym-pusht-main`](gym-pusht-main/) provides the Gymnasium PushT environment.
- [`lerobot-main`](lerobot-main/) contains LeRobot tools for datasets, policies, and robot learning.
- [`nano-world-model-main`](nano-world-model-main/) contains code for training and evaluating diffusion world models, including rollouts and planning.
- [`notebooks`](notebooks/) contains examples for simulation, data generation, policy training, and world-model evaluation.

See each project directory's README for setup instructions and project-specific details.
